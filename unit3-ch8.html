8.1 Internet vs Web ⏱️ 0–10 min

Is the internet the same as the World Wide Web?

No.

The internet is the infrastructure — the roads. The Web is one service on it — the cars.

🗣️ Think–Pair–Share (2 minutes):

Can you think of other services that run on the internet besides the Web? (e.g., email, video calls, online games.)

8.2 How the Web Works ⏱️ 10–30 min

🌐 Internet

The global network of networks.

📄 World Wide Web

The system of web pages and links that runs on the internet.

💻 Client

The device requesting information (your browser).

🖥️ Server

The computer providing information (web server).

🔗 URL

The address of a web page (like https://www.google.com).

📖 DNS (Domain Name System)

Translates domain names into IP addresses.

🔒 HTTP/HTTPS

The protocol for transferring web pages. HTTPS is secure.

📦 Packets

Data is broken into small pieces and sent across the network.

8.3 What Happens When You Type a URL? ⏱️ 30–40 min

  1. You type "www.example.com" in your browser.
  2. The browser asks DNS for the IP address.
  3. DNS returns the IP address (like 93.184.216.34).
  4. The browser sends an HTTP request to that IP.
  5. The server sends the web page back as packets.
  6. The browser assembles the packets and displays the page.

8.5 Group Activity: Build a Web Request Diagram ⏱️ 60–85 min

Work with a partner. Choose a scenario:

  • A student in Thailand opens a website hosted in the USA.
  • A gamer plays with a friend in another country.
  • A family watches a movie on a streaming service.
  • A business sends an email to a client overseas.

Draw a diagram showing: Client → DNS → Server → Response → Client.

Label each step.

👥 Suggested Group Roles

  • Designer: maps the flow of the request.
  • Writer: labels each step clearly.
  • Analyst: explains the protocol and role of DNS.
  • Presenter: presents to the class.

8.6 Why is HTTPS Important? ⏱️ 85–90 min

HTTPS is the secure version of HTTP. The "S" stands for "Secure."

HTTPS encrypts the data between your browser and the server. This means:

  • No one can read your data as it travels.
  • You can trust that the website is who it says it is.

Always look for the padlock icon in your browser. 🔒

8.7 Chapter Summary ⏱️ 95–97 min

  • The internet is the infrastructure. The Web is a service on it.
  • The web works through clients, servers, DNS, HTTP, and packets.
  • When you type a URL, the browser asks DNS for the IP address, then requests the page from the server.
  • HTTPS is the secure version of HTTP.
