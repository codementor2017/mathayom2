5.1 What Does the OS Do? ⏱️ 0–10 min

What happens when you turn on a computer?

The operating system loads first. It is the first thing that runs. It manages everything else.

What would happen if there were no operating system?

Nothing would work. The hardware would have no instructions.

🗣️ Think–Pair–Share (2 minutes):

Have you ever seen a computer that wouldn't start? What do you think went wrong?

5.2 Functions of an Operating System ⏱️ 10–30 min

⚙️ Process management

Decides which program runs and when.

🗄️ Memory management

Allocates RAM to programs.

📁 File management

Organizes files and folders.

🖨️ Device management

Controls printers, keyboards, cameras, and other devices.

🖥️ User interface

Provides the screen you interact with (GUI or command line).

🔒 Security

Manages user accounts and permissions.

Analogy: The OS is like a school principal. It manages teachers (programs), classrooms (memory), schedules (processes), and rules (security).

5.3 Common Operating Systems ⏱️ 30–40 min

  • Windows: Most common for desktops and laptops. Made by Microsoft.
  • macOS: Apple's desktop and laptop OS.
  • Linux: Open-source. Used in servers and some desktops.
  • Android: Google's mobile OS.
  • iOS: Apple's mobile OS.

5.5 Group Activity: Compare Operating Systems ⏱️ 60–85 min

Work in a group. Your teacher will assign your group an operating system: Windows, macOS, Linux, Android, or iOS.

Research and present:

  1. Who made it?
  2. What devices use it?
  3. Main features.
  4. Advantages and disadvantages.
  5. One interesting fact.

👥 Suggested Group Roles

  • Researcher: finds the facts.
  • Writer: organizes the presentation.
  • Illustrator: creates visuals or icons.
  • Presenter: delivers the presentation.

5.5b Sharing & Presentations ⏱️ 85–95 min

Each group presents their operating system.

🗣️ Peer Feedback:

Give one star and one wish.

5.6 Chapter Summary ⏱️ 95–97 min

  • The operating system is the main system software.
  • It manages processes, memory, files, devices, user interface, and security.
  • Common OSes are Windows, macOS, Linux, Android, and iOS.
  • The OS is essential for the computer to work.
