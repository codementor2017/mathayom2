1.1 True or False? ⏱️ 0–10 min

Read each statement. Decide if it is True or False.

  • 5 > 3
  • 10 = 10
  • 7 < 2
  • The sky is green.
  • You are in Grade 8.

These statements have only two possible answers: True or False.

In programming, we call these values Boolean. A Boolean is a value that is either True or False. Every comparison produces a Boolean value.

🗣️ Think–Pair–Share (2 minutes):

Can you think of any other statement that can ONLY be True or False? Share with your partner.

1.2 Comparison Operators ⏱️ 10–20 min

Python uses special symbols to compare values. These are called comparison operators.

Operator
Meaning
==
equal to
!=
not equal to
>
greater than
<
less than
>=
greater than or equal to
<=
less than or equal to

Here are some examples in Python:

print(5 > 3) # True
print(10 == 10) # True
print(7 < 2) # False
print(4 != 4) # False

Every comparison produces a Boolean value.

👩‍🏫 Tip: Remind students that == is different from =. = assigns a value; == compares two values.

1.3 Using Booleans in Decisions ⏱️ 20–30 min

Booleans are used to make decisions in programs. Here is an example:

age = 14

if age >= 13:
    print("You are a teenager.")

The if statement checks if the condition is True. If it is, the program runs the code inside.

🗣️ Quick Check (2 minutes):

What would the program print if age = 10? Why?

1.4 Predicting Boolean Results ⏱️ 30–50 min

Let's practice. What will each of these print?

a = 10
b = 5

print(a > b) # True
print(a == b) # False
print(a != b) # True
print(a <= 10) # True
print(b >= 10) # False
print(a + b > 12) # True
print(a - b == 5) # True
print(a * 2 > b * 4) # True
print(a / 2 == b) # True
print(a % 3 == 1) # True
👩‍🏫 Tip: Have students cover the comments with their hand and predict each result before revealing. Then run the code live in Python to confirm.

☕ Break Time ⏱️ 50–60 min

Stretch, hydrate, and reset your brain. When you return, you'll go on a Boolean Scavenger Hunt! 🦁

1.5 Group Activity: Boolean Scavenger Hunt ⏱️ 60–85 min

Work with a partner. Write a Python program that compares real-world values:

  • The speed of a car vs. the speed limit.
  • The temperature vs. the freezing point.
  • The height of two students.
  • The price of two items.
  • The age of two people.

Define the variables and print the Boolean result of each comparison.

Example starter:

car_speed = 80
speed_limit = 60
print(car_speed > speed_limit) # True

👥 Suggested Group Roles

  • Writer: types the code.
  • Predictor: predicts the result before running.
  • Runner: executes the code and checks output.
  • Presenter: explains the findings to the class.
👩‍🏫 Tip: Encourage students to use at least two comparison operators per example. Challenge them to use != and <= at least once.

1.5b Sharing & Presentations ⏱️ 85–95 min

Each pair will share their Boolean Scavenger Hunt code with the class.

As you listen, ask yourself:

  • Did they use the correct comparison operators?
  • Are their predictions correct?
  • Did they test at least 5 different comparisons?
🗣️ Peer Feedback:

After each presentation, give one star (something you liked) and one wish (something that could be improved).

1.6 Chapter Summary ⏱️ 95–97 min

  • A Boolean is a value that is either True or False.
  • Comparison operators produce Boolean values.
  • Booleans are used in if statements to make decisions.
  • Every comparison produces a Boolean result.

1.8 Practice & Exit Ticket ⏱️ 97–100 min

Homework: Write 5 comparison expressions and their Boolean results.

🎟️ Exit Ticket — Complete before you leave

In one sentence, explain what a Boolean is.

Then write the result of each comparison:

  • 8 > 5 → ______________________
  • 4 == 4 → ______________________
  • 7 != 7 → ______________________
  • 3 <= 2 → ______________________

🦁 “Every comparison tells a story — True or False.”
