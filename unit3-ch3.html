3.1 What Happens When You Type? ⏱️ 0–10 min

When you type a letter on a keyboard, what happens inside the computer?

The keyboard sends data to the CPU. The CPU processes it. The screen shows the letter. If you save, the letter is stored in a file.

This is the input → process → output → storage cycle.

🗣️ Think–Pair–Share (2 minutes):

What other devices or apps follow this cycle? Share examples with your partner.

3.2 The Four Stages ⏱️ 10–30 min

📥 Input

Data enters the computer.

Examples: keyboard, mouse, microphone, camera, scanner, touchscreen.

⚙️ Process

The CPU works on the data.

Examples: calculate, compare, sort, transform, decide.

📤 Output

The result is displayed or sent.

Examples: monitor, speaker, printer, projector.

💾 Storage

The data is saved for later.

Examples: hard drive, SSD, USB drive, cloud storage.

This cycle repeats constantly while the computer is running.

3.3 Examples of the Cycle ⏱️ 30–50 min

Taking a photo:

  • Input: Camera captures the image.
  • Process: CPU processes the image.
  • Output: Screen shows the photo.
  • Storage: Photo saved to storage.

Playing a game:

  • Input: Controller sends commands.
  • Process: CPU calculates game logic.
  • Output: Screen and speakers show the game.
  • Storage: Game progress is saved.
👩‍🏫 Tip: Ask students: "What if one stage fails?" (e.g., no input, no output, no storage). This shows why all four stages matter.

3.4 Group Activity: Create a Data Flow Diagram ⏱️ 60–85 min

Work with a partner. Choose one scenario:

  • ATM withdrawal.
  • Online food order.
  • Video call with a friend.
  • School attendance system.
  • Smart home device (like a smart light).

Draw a data flow diagram showing input, process, output, and storage.

Label each stage and use arrows to show the flow.

👥 Suggested Group Roles

  • Analyst: identifies each stage.
  • Illustrator: draws the diagram.
  • Presenter: explains the flow to the class.
  • Timekeeper: keeps the group on schedule.

3.4b Sharing & Presentations ⏱️ 85–95 min

Each pair presents their data flow diagram.

🗣️ Peer Feedback:

Give one star and one wish.

3.5 Chapter Summary ⏱️ 95–97 min

  • The input → process → output → storage cycle is fundamental.
  • Input enters the computer. Process works on it. Output shows the result. Storage saves it.
  • This cycle repeats constantly.
  • If one stage fails, the system cannot complete its task.
