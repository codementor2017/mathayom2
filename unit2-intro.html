📖 Welcome to Unit 2

In Unit 1, you learned how to think like a computer scientist using decomposition, pattern recognition, abstraction, and algorithm design. You learned how to break complex problems into smaller parts and create step-by-step solutions.

Now it is time to bring those skills into programming.

In this unit, you will learn how to use logic and functions to write programs that solve real problems. You will discover how to make decisions using Boolean operators, how to organize your code into reusable functions, and how to test your programs thoroughly.

🗣️ Quick Warm-Up (3 minutes):

Turn to a partner and share: What do you already know about programming? Have you ever written code before?

🎯 What You Will Be Able to Do

By the end of this unit, you will be able to design and write complete programs that use logic and functions to solve problems like:

  • Grade calculation
  • Eligibility checking
  • Inequality solving
  • Password strength checking
  • Triangle validity checking
👩‍🏫 Tip: Emphasize that programming is applied computational thinking. Every program starts with the four pillars — decomposition, pattern recognition, abstraction, and algorithm design.
