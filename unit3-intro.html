📖 Welcome to Unit 3

In Unit 1, you learned how to think like a computer scientist. In Unit 2, you learned how to use logic and functions to write programs.

Now it is time to look at the machine itself.

What is inside a computer? How does it work? How do computers talk to each other? How does the internet deliver a web page to your screen in less than a second?

In this unit, you will learn about the components of a computer system, how data flows through a computer, what software does, how operating systems manage everything, how networks connect devices, and how communication technology has changed the world.

🗣️ Quick Warm-Up (3 minutes):

What device are you using right now? What do you think is inside it? Share with your partner.

🎯 What You Will Be Able to Do

By the end of this unit, you will be able to design a complete system that uses hardware, software, and communication technology to solve a real problem.
