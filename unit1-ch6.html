6.1 The Line-Up Challenge ⏱️ 0–10 min

If your class had to line up by height in 60 seconds, how would you do it?

Today we compare different algorithms for the same problem.

🗣️ Think–Pair–Share (2 minutes):

Without using any specific method, how would you quickly line up 10 classmates by height? Share your idea with a partner.

6.2 Three Sorting Algorithms ⏱️ 10–25 min

Here are three different ways to sort a group by height.

🔄 Bubble Sort: Compare and swap neighbors

  • Compare first two. Swap if wrong order.
  • Move to next pair. Repeat.
  • After each pass, the tallest "bubbles" to the end.

🎯 Selection Sort: Find the shortest, put first

  • Find the shortest person in the group.
  • Move them to the front.
  • Find the next shortest. Move to second position.
  • Repeat.

🌳 Merge Sort: Divide and conquer

  • Divide the group into two halves.
  • Sort each half.
  • Merge the two sorted halves.
👩‍🏫 Tip: Use 8 students with visibly different heights to demonstrate each algorithm once. Ask: "Which felt fastest? Which felt easiest to understand?"

Best for different sizes:

  • Bubble sort is simple but slow for large groups.
  • Selection sort is faster for small groups.
  • Merge sort is fastest for large groups.
🗣️ Quick Check (2 minutes):

If you had to line up 100 students, which algorithm would you pick? Why?

☕ Break Time ⏱️ 45–55 min

Stretch, hydrate, and reset your brain. When you return, you'll race the algorithms! 🦁

6.4 Sorting Race ⏱️ 55–80 min

Divide the class into three teams.

  • Team A uses Bubble Sort.
  • Team B uses Selection Sort.
  • Team C uses Merge Sort.

Round 1: Give each team 8 students with different heights (or 8 cards with numbers).

Time how long each team takes to sort.

Round 2: Repeat with 12 students/cards.

Then discuss:

  • Which algorithm was faster?
  • Did the result change with more items?
  • Which algorithm was easiest to follow?

👥 Suggested Team Roles

  • Sorters: physically line up in order.
  • Caller: reads the algorithm steps aloud.
  • Timekeeper: records the time on the board.
  • Recorder: writes down observations for the class discussion.
👩‍🏫 Tip: Use index cards with numbers instead of students if you want more rounds. It's faster and easier to manage. The key learning moment is when students notice that merge sort's advantage grows with more items.

6.5 Activity: Design a Faster Algorithm ⏱️ 80–95 min

Can you design a faster way to line up by height?

Brainstorm and test:

  1. Divide into two groups: shorter half and taller half.
  2. Sort each half.
  3. Merge the two halves.

Test your algorithm with 10 cards.

Compare with bubble sort.

🗣️ Class Discussion (5 minutes):

Which algorithm was fastest in your test? Did it matter if the cards were already partially sorted? Why?

6.6 Chapter Summary ⏱️ 95–97 min

  • There are many ways to sort items.
  • Bubble sort is simple but slow.
  • Selection sort is faster for small groups.
  • Merge sort is fastest for large groups.
  • Different algorithms work better for different sizes of problems.

Homework: Write the steps of your favorite sorting algorithm in your own words.

In one sentence, explain why merge sort is faster for large groups.

Then match the algorithm to its best use:
