3.1 The Copy-Paste Problem ⏱️ 0–10 min

Look at this program. It calculates the area of three rectangles.

length1 = 5
width1 = 3
area1 = length1 * width1
print("Area 1 =", area1)

length2 = 7
width2 = 2
area2 = length2 * width2
print("Area 2 =", area2)

length3 = 10
width3 = 4
area3 = length3 * width3
print("Area 3 =", area3)

What is repeated? The formula for area (length × width) is repeated three times.

How can we make this shorter? We can use a function.

A function is a named block of code that does one job. We can reuse it.

🗣️ Think–Pair–Share (2 minutes):

Can you think of any chores or tasks you do the same way every day? How could "wrapping" them into a single instruction save you time?

3.2 Writing Functions ⏱️ 10–30 min

Here is the function syntax:

def function_name(parameters):
    # code
    return result

Here is the area example with a function:

def area(length, width):
    return length * width

print("Area 1 =", area(5, 3))
print("Area 2 =", area(7, 2))
print("Area 3 =", area(10, 4))

Let's understand each part:

  • def starts the function.
  • area is the function name.
  • length and width are parameters (inputs).
  • 5, 3 are arguments (values passed to the function).
  • return sends the result back.
  • area(5, 3) calls the function.

Functions are abstraction — they hide the details.

👩‍🏫 Tip: Explain the difference between parameters (the variables in the definition) and arguments (the actual values passed in when calling). Use the "form vs. filled-in form" analogy.

3.3 Your First Functions ⏱️ 30–50 min

Here are some basic functions:

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "Cannot divide by zero"
    return a / b

Why did we add a check for zero in divide?

Because dividing by zero causes an error.

🗣️ Quick Check (2 minutes):

What would add(3, 4) return? What about divide(10, 0)? Discuss with your neighbor.

☕ Break Time ⏱️ 50–60 min

Stretch, hydrate, and reset your brain. When you return, you'll build your own math function library! 🦁

3.4 Group Activity: Function Library ⏱️ 60–85 min

Work with a partner. Create a "math function library" with at least 5 functions:

  • square(n) — returns n²
  • cube(n) — returns n³
  • average(a, b, c) — returns the average
  • is_even(n) — returns True or False
  • max_of_two(a, b) — returns the larger number

Test each function.

Swap with another pair and test each other's functions.

👥 Suggested Group Roles

  • Writer A: writes functions 1–3.
  • Writer B: writes functions 4–5.
  • Tester: runs each function with sample inputs.
  • Presenter: explains the library to the class.
👩‍🏫 Tip: Encourage students to add helpful print statements with labels (e.g., print("square(4) =", square(4))) so testing is clear and easy to read.

3.4b Swap & Test ⏱️ 85–95 min

Exchange your function library with another group.

Test their functions with your own inputs.

As you test, ask yourself:

  • Do their functions do what they say?
  • Are the function names clear?
  • Do they handle edge cases (e.g., average(0, 0, 0))?
  • Did they use return correctly?
🗣️ Peer Feedback:

Give the other group one star (something you liked) and one wish (something that could be improved).

3.5 Chapter Summary ⏱️ 95–97 min

  • A function is a named block of code that does one job.
  • Functions make code reusable and shorter.
  • Parameters are inputs. Arguments are values passed to the function.
  • return sends the result back.
  • Functions are abstraction — they hide the details.
