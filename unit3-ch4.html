4.1 What Software Do You Use? ⏱️ 0–10 min

What software or apps do you use every day?

Windows, Android, Chrome, Word, TikTok, games, calculator.

Which ones run the computer itself? Which ones do a specific job?

🗣️ Think–Pair–Share (2 minutes):

List three apps you used today. Which ones do you think "run" the computer?

4.2 Two Types of Software ⏱️ 10–30 min

📀 System Software

Runs the computer and manages hardware.

Examples:

  • Operating systems: Windows, macOS, Linux, Android, iOS.
  • Utility programs: antivirus, disk cleaner, backup.
  • Device drivers: printer driver, graphics driver.

🎨 Application Software

Does a specific task for the user.

Examples:

  • Productivity: Word, Excel, PowerPoint.
  • Communication: Zoom, LINE, Gmail.
  • Entertainment: games, YouTube, Spotify.
  • Education: Khan Academy, Duolingo.
  • Creative: Photoshop, Canva.

System software runs the computer. Application software helps you do tasks.

Analogy: System software is like the road. Application software is like the cars on the road. Without the road, the cars cannot go anywhere.

4.5 Chapter Summary ⏱️ 95–97 min

  • System software runs the computer and manages hardware.
  • Application software does a specific task for the user.
  • System software is required for application software to run.
  • Examples of system software: operating systems, utilities, drivers.
  • Examples of application software: productivity, communication, entertainment, education, creative tools.
