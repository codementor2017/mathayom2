5.1 Follow the Instructions ⏱️ 0–10 min

Imagine you ask someone to make a sandwich.

They say: "Put peanut butter on bread."

But they forgot to say "open the jar." So you put the closed jar on the bread.

What was missing? The instructions were not clear.

An algorithm must be clear and complete.

🗣️ Think–Pair–Share (2 minutes):

Have you ever followed instructions that were missing a step? What happened? Share with your partner.

5.2 Parts of an Algorithm ⏱️ 10–25 min

Every algorithm has three parts:

📥

Input

What do we start with?

⚙️

Process

What steps do we follow?

📤

Output

What do we end with?

Rules for algorithms:

  • Clear steps.
  • Correct order.
  • Finite (has an end).
  • No ambiguity.
👩‍🏫 Tip: Ask students: "What happens if we swap step 1 and step 2 of making a sandwich?" This shows why order matters.

5.3 Example: Algorithm to Line Up by Height ⏱️ 25–35 min

Input: A group of students with different heights.

Process:

  1. Stand in a line.
  2. Compare the first two people. If the first is taller, swap them.
  3. Move to the next pair. Repeat.
  4. Continue until no swaps are needed.

Output: A line ordered from shortest to tallest.

🗣️ Quick Check (2 minutes):

Why is "continue until no swaps are needed" important? What if we stopped early?

5.4 Pseudocode ⏱️ 35–45 min

Pseudocode is a simple way to write an algorithm.

START
LINE UP students randomly

REPEAT
    FOR each pair of students
        IF first is taller than second THEN
            SWAP them
        END IF
    END FOR
UNTIL no swaps needed

END

Notice how pseudocode uses everyday language mixed with clear structure. It is not tied to any programming language.

☕ Break Time ⏱️ 45–55 min

Stretch, hydrate, and reset your brain. When you return, you'll write and compare your own algorithms! 🦁

5.5 Activity: Write an Algorithm for Lining Up ⏱️ 55–65 min

How can our class line up by height as quickly as possible?

Write an algorithm:

  1. Step 1: Everyone stands in a random line.
  2. Step 2: Compare the first two people; swap if the first is taller.
  3. Step 3: Move to the next pair; repeat.
  4. Step 4: After one full pass, the tallest is at the end.
  5. Step 5: Repeat passes until the line is sorted.

Test the algorithm with 5 volunteers.

  • Time how long it takes.
  • Can you make it faster?
👩‍🏫 Tip: Use 5 students with visibly different heights. Have the class count the swaps out loud. Record the time on the board.

5.6 Activity: Write and Compare Algorithms ⏱️ 65–80 min

Work in a group. Choose a task:

  • Arrange shirts to find them easily.
  • Organize a bookshelf.
  • Pack a suitcase for a 3-day trip.
  • Set the table for a family dinner.
  • Prepare a study plan for 5 subjects.

Write two different algorithms for the same task.

Then compare:

  • Which is faster?
  • Which is easier to follow?
  • Which uses fewer steps?

Test by having another group follow the steps exactly.

👥 Suggested Group Roles

  • Writer A: writes algorithm 1.
  • Writer B: writes algorithm 2.
  • Tester: reads the algorithm aloud step by step.
  • Timer: measures how long each algorithm takes.

5.6b Gallery Walk & Presentations ⏱️ 80–95 min

Each group will present their two algorithms. The class will compare and discuss.

As you listen, ask yourself:

  • Is the algorithm clear and complete?
  • Is the order correct?
  • Does it have a clear end?
  • Which algorithm is more efficient?

Then each group's Presenter gives a 2-minute explanation of their comparison.

🗣️ Peer Feedback:

After each presentation, give one star (something you liked) and one wish (something that could be improved).

5.7 Chapter Summary ⏱️ 95–97 min

  • An algorithm is a clear, ordered set of steps.
  • Every algorithm has input, process, and output.
  • Algorithms must be clear, ordered, finite, and unambiguous.
  • There is often more than one algorithm for the same problem.

5.8 Key Words

Word
Meaning
Algorithm
A clear, ordered set of steps
Sequence
The order of steps

The arrangement of steps
Step
One action in an algorithm
Input
What goes into the algorithm
Output
What comes out of the algorithm
Process
The steps in between
Test
Try the algorithm with different inputs
Compare
Look at differences and similarities
Efficiency
Getting the best result with the least effort

5.9 Practice & Exit Ticket ⏱️ 97–100 min

Homework: Write a 5-step algorithm for a task you do every morning.

🎟️ Exit Ticket — Complete before you leave

In one sentence, explain what an algorithm is.

Then write the 3 parts of every algorithm:

  1. ______________________
  2. ______________________
  3. ______________________
