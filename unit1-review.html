📘 What You Learned ⏱️ 0–10 min

In this unit, you learned:

  • What computational thinking is.
  • The four pillars of computational thinking.
  • How to decompose complex problems.
  • How to find patterns and create rules.
  • How to create abstractions and models.
  • How to design and compare algorithms.
  • How to test algorithms with different cases.
  • How to combine all four pillars.
  • How to complete a computational thinking project.

🔑 Vocabulary Review ⏱️ 10–30 min

Review the key words from Unit 1:

Word
Meaning
Computational thinking
A formal way of solving problems like a computer scientist
Decomposition
Breaking a problem into smaller parts
Sub-problem
A smaller part of a bigger problem
Tree diagram
A diagram that shows the structure of a problem
Pattern
A repeating or similar structure
Pattern recognition
Finding similarities or repeating rules
Rule
A general instruction
Abstraction
Removing unnecessary details to focus on important ones
Model
A simplified representation of a problem
Algorithm
A clear, ordered set of steps
Sequence
The order of steps
Input
What goes into the algorithm
Output
What comes out of the algorithm
Test
Try the algorithm with different inputs
Debug
Find and fix errors
Edge case
A situation at the limit
Boundary case
An input at the edge
Bubble sort
Compare and swap neighbors
Selection sort
Find the smallest, put first
Merge sort
Divide, sort, and merge
Efficiency
Getting the best result with the least effort

🧠 Concept Check ⏱️ 30–50 min

Apply all four pillars to this mini problem:

"Plan a class picnic for 30 students."

🧩 Decomposition

Break into: Venue, Food, Transport, Activities, Permission, Safety.

🔍 Pattern Recognition

Last year's picnic worked well — reuse the schedule format.

🎯 Abstraction

Essential: number of students, budget, date. Non-essential: napkin color, music playlist.

📋 Algorithm

  1. Choose date.
  2. Book venue.
  3. Plan menu.
  4. Arrange transport.
  5. Send permission forms.
  6. Assign activities.
  7. Prepare first aid.
  8. Run picnic.
  9. Collect feedback.
  10. Evaluate.
🗣️ Class Discussion (5 minutes):

Which pillar did you find most useful for this problem? Why?
