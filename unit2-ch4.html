4.1 Functions That Decide ⏱️ 0–10 min

Can a function return True or False?

Yes. A Boolean function returns True or False.

def is_adult(age):
    return age >= 18

print(is_adult(15)) # False
print(is_adult(20)) # True
🗣️ Think–Pair–Share (2 minutes):

What other "yes/no" questions could a function answer? (e.g., "Is this number even?", "Is this password strong?")

4.2 Boolean Functions ⏱️ 10–20 min

Here are more examples:

def is_even(n):
    return n % 2 == 0

def is_positive(n):
    return n > 0

def is_between(n, low, high):
    return n >= low and n <= high

These functions use Boolean logic to decide.

👩‍🏫 Tip: Ask students: "What is the difference between is_even and add?" (One returns True/False; the other returns a number.) Boolean functions are called predicates in programming.

4.3 Functions with if/else ⏱️ 20–30 min

Functions can also contain if/else to return different results.

def grade(score):
    if score >= 80:
        return "A"
    elif score >= 70:
        return "B"
    elif score >= 60:
        return "C"
    elif score >= 50:
        return "D"
    else:
        return "F"

Functions can contain logic and return different results.

🗣️ Quick Check (2 minutes):

What would grade(75) return? What about grade(50)?

4.4 Combining Logic and Functions ⏱️ 30–50 min

Here are more examples:

def is_leap_year(year):
    return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

def is_valid_triangle(a, b, c):
    return a + b > c and b + c > a and a + c > b

def is_strong_password(password):
    return len(password) >= 8 and any(c.isdigit() for c in password)

Boolean logic makes these functions powerful.

👩‍🏫 Tip: Walk through is_leap_year step by step. Ask: "Why do we need BOTH the century check and the 400 check?" Show examples: 2000 (True), 1900 (False), 2024 (True), 2023 (False).

☕ Break Time ⏱️ 50–60 min

Stretch, hydrate, and reset your brain. When you return, you'll build your own logic function library! 🦁

4.5 Group Activity: Logic Function Library ⏱️ 60–85 min

Work with a partner. Write at least 5 Boolean or logic-based functions:

  • is_prime(n) — checks if a number is prime.
  • is_passing(score) — score ≥ 50.
  • can_vote(age, citizen) — age ≥ 18 and citizen.
  • is_weekend(day) — day is "Saturday" or "Sunday".
  • discount_eligible(age, member) — age < 12 or age > 65 or member.

Test each function with at least 3 inputs.

👥 Suggested Group Roles

  • Writer A: writes is_prime and is_passing.
  • Writer B: writes can_vote, is_weekend, discount_eligible.
  • Tester: runs each function with 3+ inputs.
  • Presenter: explains the library to the class.
👩‍🏫 Tip: For is_prime, students may need a hint: "A prime number is only divisible by 1 and itself." Suggest checking divisibility from 2 to n-1, or use range(2, n).

4.5b Swap & Test ⏱️ 85–95 min

Exchange your logic function library with another group.

Test their functions with your own inputs.

As you test, ask yourself:

  • Do their functions return the correct True/False value?
  • Did they handle edge cases (e.g., is_prime(1), is_prime(2))?
  • Are their function names clear?
  • Did they use Boolean operators correctly?
🗣️ Peer Feedback:

Give the other group one star (something you liked) and one wish (something that could be improved).

4.6 Chapter Summary ⏱️ 95–97 min

  • Boolean functions return True or False.
  • Functions can contain if/else to return different results.
  • Boolean logic makes functions powerful.
  • Functions can combine multiple conditions.
