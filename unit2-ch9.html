9.2 Design a Complete Program ⏱️ 10–30 min

Problem: A school wants a program to check if a student can join the science competition.

Rule: GPA ≥ 3.0 AND science score ≥ 80 AND attendance ≥ 90%.

  • If eligible: Print "Eligible" and the student's rank (Gold, Silver, Bronze based on score).
  • If not: Print "Not eligible" and the reason.

Functions:

  • is_eligible(gpa, score, attendance)
  • rank(score)
  • reason(gpa, score, attendance)
👩‍🏫 Tip: Show students how the three functions work together: is_eligible decides, rank classifies, and reason explains a failure.

9.3 Building the Program ⏱️ 30–50 min

Here is the code:

def is_eligible(gpa, score, attendance):
    return gpa >= 3.0 and score >= 80 and attendance >= 90

def rank(score):
    if score >= 95:
        return "Gold"
    elif score >= 90:
        return "Silver"
    else:
        return "Bronze"

def reason(gpa, score, attendance):
    if gpa < 3.0:
        return "GPA too low"
    if score < 80:
        return "Science score too low"
    if attendance < 90:
        return "Attendance too low"
    return "Eligible"

Main program:

gpa = float(input("GPA: "))
score = float(input("Science score: "))
attendance = float(input("Attendance (%): "))

if is_eligible(gpa, score, attendance):
    print("Eligible - Rank:", rank(score))
else:
    print("Not eligible - Reason:", reason(gpa, score, attendance))
🗣️ Quick Check (2 minutes):

Why does reason use separate if statements instead of elif? What happens if a student fails two conditions?

9.4 Group Activity: Design Your Own Complete Program ⏱️ 60–85 min

Work with a partner. Choose one problem:

  • Check if a person can get a loan (income, credit score, age).
  • Check if a student qualifies for a scholarship (GPA, activities, income).
  • Check if a customer gets free shipping (total, member, location).
  • Check if a triangle is valid and classify it (equilateral, isosceles, scalene).

Design functions. Write logic. Write code. Test with 3 cases.

👥 Suggested Group Roles

  • Designer: decides the functions and conditions.
  • Writer: types the code.
  • Tester: runs normal, boundary, and invalid cases.
  • Presenter: explains the program to the class.
👩‍🏫 Tip: Encourage students to reuse patterns from earlier chapters. Most programs will have an is_...() check, a reason() or rank(), and a main if block.

9.4b Sharing & Presentations ⏱️ 85–95 min

Each pair will demo their program and explain their logic.

As you listen, ask yourself:

  • Did they use at least 3 functions?
  • Did they use Boolean logic correctly?
  • Did they test with all 3 case types?
  • Is the program clear and useful?

9.5 Chapter Summary ⏱️ 95–97 min

  • A complete program uses functions and logic together.
  • Functions make the program easier to design and test.
  • Boolean logic helps make decisions.
  • Testing with different cases makes the program reliable.
