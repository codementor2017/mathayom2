2.1 What's Inside? ⏱️ 0–10 min

Look at a picture of the inside of a computer. What do you see?

There are many parts. Each part has a specific job.

🗣️ Think–Pair–Share (2 minutes):

Have you ever opened a computer or seen its inside? What did you notice?

2.2 The Main Components ⏱️ 10–30 min

🧠 CPU (Central Processing Unit)

The "brain." It processes instructions and performs calculations.

🗄️ RAM (Random Access Memory)

Temporary storage for active programs and data. When you turn off the computer, RAM is cleared.

📚 ROM (Read-Only Memory)

Permanent storage for startup instructions. The computer uses ROM to boot up.

🧩 Motherboard

The main circuit board that connects all components.

🗃️ Hard Drive / SSD

Long-term storage for files and programs. The hard drive keeps data even when the power is off.

🎨 GPU (Graphics Processing Unit)

Handles images, video, and 3D graphics.

⚡ Power Supply

Provides electricity to all components.

❄️ Cooling System

Fans and heat sinks keep components from overheating.

🛣️ Bus

The pathways that carry data between components.

2.3 An Analogy: A Computer is Like a Kitchen ⏱️ 30–40 min

Think of a computer as a kitchen.

  • CPU = chef. The chef does the work.
  • RAM = countertop. The countertop is the temporary workspace.
  • Hard drive = refrigerator. The refrigerator stores food for later.
  • Motherboard = kitchen layout. The layout connects everything.
  • Power supply = electricity. Electricity provides energy.
  • Cooling system = ventilation. Ventilation keeps the kitchen from overheating.

2.4 Match Components to Functions ⏱️ 40–50 min

Read each function. Which component does it describe?

  • Processes instructions → CPU
  • Stores files permanently → Hard drive / SSD
  • Holds data temporarily while working → RAM
  • Connects all components → Motherboard
  • Provides electricity → Power supply
  • Handles graphics → GPU
  • Keeps components cool → Cooling system
  • Carries data between parts → Bus
  • Stores startup instructions → ROM
  • The main circuit board → Motherboard
🗣️ Quick Check (2 minutes):

Which component do you think is the most important? Why?

2.6 Chapter Summary ⏱️ 95–97 min

  • The main internal components are the CPU, RAM, ROM, motherboard, storage, GPU, power supply, cooling system, and bus.
  • Each component has a specific job.
  • All components work together.
  • If one component fails, the system may not work.
