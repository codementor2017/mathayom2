2.1 Combining Conditions ⏱️ 0–10 min

Imagine a roller coaster rule: You must be at least 12 years old AND at least 140 cm tall.

If you are 13 years old and 135 cm tall, can you ride?

You are old enough (13 ≥ 12), but you are not tall enough (135 < 140). Because the rule requires BOTH conditions, you cannot ride.

Now imagine the rule is OR instead of AND. Can you ride?

With OR, you only need one condition to be true. Since you are old enough, you can ride.

Boolean operators combine conditions.

🗣️ Think–Pair–Share (2 minutes):

Can you think of another real-life rule that uses AND or OR? (e.g., "You can get a discount if you are a student OR a senior.")

2.2 The Three Boolean Operators ⏱️ 10–20 min

Python has three Boolean operators:

🔗

and

True only if BOTH conditions are True.

➕

or

True if AT LEAST ONE condition is True.

🔄

not

Reverses the value.

👩‍🏫 Tip: Use hand gestures. "AND" = both hands raised (both must be true). "OR" = one hand raised (at least one is enough). "NOT" = flip your hand over.

2.4 Examples in Python ⏱️ 30–40 min

age = 13
height = 135

print(age >= 12 and height >= 140) # False
print(age >= 12 or height >= 140) # True
print(not (age >= 12)) # False
🗣️ Quick Check (2 minutes):

What if age = 11 and height = 145? What would each line print? Discuss with your neighbor.

2.5 Combining Conditions in Real Life ⏱️ 40–50 min

Here are some real scenarios:

  • A student passes if score ≥ 50 AND attendance ≥ 80%.
  • A number is valid if it is between 1 and 100.
  • A password is strong if it has at least 8 characters AND contains a number.
  • A person can vote if age ≥ 18 AND is a citizen.
  • Free shipping if total ≥ 500 OR member = True.

Here is a Python example:

score = 65
attendance = 85

if score >= 50 and attendance >= 80:
    print("Pass")
else:
    print("Fail")
👩‍🏫 Tip: Ask students to predict the output before running. Then change attendance to 75 and ask again. This reinforces the "and" rule.

2.6 Group Activity: Compound Conditions Program ⏱️ 60–85 min

Work with a partner. Choose one scenario:

  • Movie ticket discount: age < 12 OR age > 65.
  • Scholarship: GPA ≥ 3.5 AND activities ≥ 3.
  • Safe driving: speed ≤ 90 AND seatbelt = True.
  • Valid triangle: a + b > c AND b + c > a AND a + c > b.

Write a Python program that:

  1. Uses at least two Boolean operators.
  2. Tests with at least 3 different inputs.
  3. Prints a clear result (e.g., "Eligible" or "Not eligible").

Example starter (movie ticket):

age = 10

if age < 12 or age > 65:
    print("Discount ticket")
else:
    print("Full price ticket")

👥 Suggested Group Roles

  • Writer: types the code.
  • Predictor: predicts the output for each test input.
  • Tester: runs the code with 3+ different inputs.
  • Presenter: explains the logic to the class.
👩‍🏫 Tip: Encourage students to use parentheses when combining conditions — e.g., (age < 12) or (age > 65). It makes the logic clearer.

2.6b Sharing & Presentations ⏱️ 85–95 min

Each pair will present their compound conditions program.

As you listen, ask yourself:

  • Did they use at least two Boolean operators?
  • Are their predictions correct?
  • Did they test with at least 3 different inputs?
  • Is the logic clear and correct?
🗣️ Peer Feedback:

After each presentation, give one star (something you liked) and one wish (something that could be improved).

2.7 Chapter Summary ⏱️ 95–97 min

  • and is True only if both conditions are True.
  • or is True if at least one condition is True.
  • not reverses the value.
  • Truth tables show all possible outcomes.
  • Boolean operators combine conditions in if statements.
