🧠 Concept Check ⏱️ 30–50 min

Build a mini eligibility program using logic and functions.

"Check if a person can rent a car. Rule: age ≥ 21 AND has a driver's license."

📥 Input

age, has_license

📤 Output

"Can rent" or "Cannot rent"

📦 Function

can_rent(age, has_license)

🧠 Boolean condition

age >= 21 and has_license == True

📋 Pseudocode

FUNCTION can_rent(age, has_license)
    RETURN age >= 21 AND has_license
END FUNCTION

🧪 Test cases

  • Normal: age=25, license=True → True
  • Boundary: age=21, license=True → True
  • Invalid: age=20, license=True → False

Now write the actual Python code yourself:

def can_rent(age, has_license):
    return ______________________

age = int(input("Age: "))
has_license = input("Has license? (yes/no): ") == "yes"

if can_rent(age, has_license):
    print("Can rent")
else:
    print("Cannot rent")
🗣️ Class Discussion (5 minutes):

Why is age >= 21 better than age > 20? What happens if someone is exactly 21 years old?
