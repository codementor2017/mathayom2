📘 What You Learned ⏱️ 0–10 min

In this unit, you learned:

  • What a computer system is and its five components.
  • The main internal hardware components.
  • How the input → process → output → storage cycle works.
  • The difference between system software and application software.
  • What an operating system does.
  • What communication technology is.
  • How networks connect devices.
  • How the internet and the World Wide Web work.
  • How wireless communication technology works.
  • How to design a complete system.

🧠 Concept Check ⏱️ 30–50 min

Design a mini system using all three parts: hardware, software, and communication.

"Design a smart bell system for a school. It rings automatically at the correct time and sends a notification to the office if it fails."

🖥️ Hardware

Bell, timer, microcontroller, Wi-Fi module, office computer.

📀 Software

Scheduling app, notification system, dashboard.

📡 Communication

Wi-Fi (to send notifications) or Bluetooth (local control).

🔄 Data Flow

Input: current time (from the clock). Process: compare to schedule. Output: ring the bell. Storage: log the event and report failures.

✅ How it solves the problem

Automatic ringing saves time and keeps the school on schedule. Notifications help staff respond quickly when something goes wrong.

🗣️ Class Discussion (5 minutes):

Which part of your system is the most critical? What happens if it fails?
