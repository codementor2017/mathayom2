6.1 What is a Grade Calculator? ⏱️ 0–10 min

How does your school decide your letter grade?

Most schools use a scale like this:

  • 80–100: A
  • 70–79: B
  • 60–69: C
  • 50–59: D
  • 0–49: F

Today we will build a grade calculator that uses functions and logic.

🗣️ Think–Pair–Share (2 minutes):

What do you think are the "boundary scores" where the grade changes? Why are they important?

6.2 Building the Program ⏱️ 10–30 min

First, define the grading scale. Then write the function:

def grade(score):
    if score >= 80:
        return "A"
    elif score >= 70:
        return "B"
    elif score >= 60:
        return "C"
    elif score >= 50:
        return "D"
    else:
        return "F"

Add input validation:

def grade(score):
    if score < 0 or score > 100:
        return "Invalid score"
    elif score >= 80:
        return "A"
    ...

Main program:

score = float(input("Enter score: "))
print("Grade:", grade(score))
👩‍🏫 Tip: Highlight why elif is used instead of separate if statements. It ensures the first matching condition wins.

6.3 Adding Multiple Scores ⏱️ 30–50 min

Let's extend the program to handle multiple scores.

def grade(score):
    ...

def average(scores):
    return sum(scores) / len(scores)

scores = []
for i in range(5):
    s = float(input("Enter score: "))
    scores.append(s)

avg = average(scores)
print("Average:", avg)
print("Final grade:", grade(avg))

What if the score is exactly 80? Exactly 50? These are boundary cases.

🗣️ Quick Check (2 minutes):

Why do we need to test with boundary scores like 80, 70, 60, and 50?

☕ Break Time ⏱️ 50–60 min

Stretch, hydrate, and reset your brain. When you return, you'll improve the grade calculator! 🦁

6.4 Group Activity: Improve the Grade Calculator ⏱️ 60–85 min

Work with a partner. Improve the program by adding at least two of the following:

  • A function to count how many students passed.
  • A loop to input scores until the user types "done".
  • A function that returns both the grade and a comment.
  • A function that calculates the GPA (A=4, B=3, C=2, D=1, F=0).

Test your program with at least 3 different score sets.

👥 Suggested Group Roles

  • Writer: types the code.
  • Tester: runs the program with different scores.
  • Debugger: fixes errors and boundary issues.
  • Presenter: explains the improvements to the class.
👩‍🏫 Tip: Challenge advanced groups to add an "A+" for scores ≥ 95 and an "F" for scores below 50. Ask: "Where should the new boundary go?"

6.4b Sharing & Presentations ⏱️ 85–95 min

Each pair will present their improved calculator.

As you listen, ask yourself:

  • Did they add at least two improvements?
  • Did they test with boundary cases?
  • Is the program clear and easy to use?
🗣️ Peer Feedback:

Give one star (something you liked) and one wish (something that could be improved).

6.5 Chapter Summary ⏱️ 95–97 min

  • A grade calculator uses functions and logic.
  • Boundary cases are important to test.
  • Functions can be reused for different inputs.
  • Input validation makes programs more reliable.
