7.1 What is an Inequality? ⏱️ 0–10 min

An inequality is a statement that two values are not equal.

Example: x + y < 10.

What are some solutions? (x=1, y=2; x=3, y=5; etc.)

How many solutions are there? Many.

We can use a program to find all solutions.

🗣️ Think–Pair–Share (2 minutes):

Can you think of one solution to x + y < 10 where x and y are positive whole numbers? Share with a partner.

7.2 Solving with Nested Loops ⏱️ 10–30 min

To find all solutions, we try every possible value.

A nested loop is a loop inside another loop.

for x in range(1, 11):
    for y in range(1, 11):
        if x + y < 10:
            print(x, y)

Let's understand:

  • Outer loop: x from 1 to 10.
  • Inner loop: y from 1 to 10.
  • Condition: x + y < 10.

This is called brute force — try everything.

👩‍🏫 Tip: Ask students: "How many total (x, y) pairs are checked?" Answer: 10 × 10 = 100 pairs. This makes the idea of "trying everything" concrete.

7.3 Solving Different Inequalities ⏱️ 30–50 min

Here are more inequalities to solve:

  • x + y < 10 (positive integers)
  • 2x + 3y <= 20
  • x * y > 20
  • x² + y² < 50

For each, ask: How many solutions? What is the range of x and y?

🗣️ Quick Check (2 minutes):

Which inequality do you think has the most solutions? Why?

☕ Break Time ⏱️ 50–60 min

Stretch, hydrate, and reset your brain. When you return, you'll build your own inequality solver! 🦁

7.4 Group Activity: Inequality Solver with Functions ⏱️ 60–85 min

Work with a partner. Write a program with functions:

def find_solutions(limit):
    solutions = []
    for x in range(1, limit + 1):
        for y in range(1, limit + 1):
            if x + y < 10:
                solutions.append((x, y))
    return solutions

def count_solutions(solutions):
    return len(solutions)

def show_solutions(solutions):
    for s in solutions:
        print(s)

Test with different limits. Extend to other inequalities.

👥 Suggested Group Roles

  • Writer: types the code.
  • Tester: runs with different limits.
  • Extender: tries a new inequality.
  • Presenter: explains the results to the class.

7.4b Sharing & Presentations ⏱️ 85–95 min

Each pair will present their inequality solver.

As you listen, ask yourself:

  • Did they use nested loops correctly?
  • Did they count and display the solutions?
  • Did they try a new inequality?

7.5 Chapter Summary ⏱️ 95–97 min

  • An inequality is a statement that two values are not equal.
  • Nested loops try every possible value.
  • Brute force means trying everything.
  • Functions make the program easier to modify.
